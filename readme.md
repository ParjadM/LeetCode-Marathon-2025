## 📖 About This Repository
This repository documents my intense 6-week Data Structures & Algorithms sprint. The goal is to master problem-solving patterns, improve coding speed, and build deep intuition for Time/Space complexity.

**The Rules:**
1.  **No Tutorials First:** Attempt every problem for 20 mins before looking at hints.
2.  **Deep Work:** 50/10 Pomodoro cycles during study blocks.
3.  **Documentation:** Every solution includes Time/Space complexity analysis.
